# Royal Sky Blue Wedding Invitation

## Folder structure

```text
wedding-invitation/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── bride-cutout.png
    ├── groom-cutout.png
    └── wedding-song.mp3
```

## Setup

1. Open `index.html` in your browser.
2. Put your bride cutout photo at `assets/bride-cutout.png`.
3. Put your groom cutout photo at `assets/groom-cutout.png`.
4. Put your wedding music at `assets/wedding-song.mp3`.
5. Open `script.js` and change `weddingDate` to your exact wedding date/time.
6. Edit the names, dates, venue, timings and story text in `index.html`.

### Important note about music

Modern browsers normally block audio autoplay. The visitor can tap the **Music** button to start the song. This is expected browser behaviour.

### Couple cutout photos

Transparent PNG files work best because the design is built around the couple appearing as floating cutouts. If your photos have backgrounds, remove the backgrounds first for the intended look.

### Location button

The event cards contain `View Location` placeholders. Replace the `href="#"` values with your Google Maps link.

No framework is required — this is plain HTML, CSS and JavaScript.
